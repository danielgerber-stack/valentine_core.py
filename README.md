# Valentine Organism v1.0 🤖⚡

O **Valentine Organism** é um sistema autônomo de automação, periféricos e robótica.

## 🚀 Como Executar

1. Baixe o repositório.
2. Abra o arquivo `valentine_core.py` e insira sua chave na variável `API_KEY`.
3. Dê dois cliques no arquivo `run.bat`.

## 🎮 Comandos
* **`Viva`**: Ativa o modo de autonomia contínua.
* **`ESC`**: Interrompe o modo autônomo instantaneamente.
* **`sair`**: Encerra o programa.
